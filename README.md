# NovelNest Android

Android web-novel reader prototype with text-to-speech and background playback support.

## Source archive
The complete Android Studio project is provided in `NovelNest-Android-Buildable-Source.zip`. The workflow extracts it and attempts to build a debug APK with GitHub Actions.

## Build status
This is a prototype, not a fully tested release. It currently uses sample chapter content; a real novel catalogue/source integration and additional natural voice options are not implemented.

After a successful workflow run, download the `NovelNest-debug-apk` artifact from the Actions run page.
